### 🚀 Tentang Saya

Saya adalah siswa **Teknik Jaringan Komputer dan Telekomunikasi (TJKT)** di **SMK Negeri 1 Majalengka** yang memiliki ketertarikan besar terhadap teknologi, pengembangan perangkat lunak, jaringan komputer, dan desain digital.

> *"Saya percaya bahwa teknologi bukan sekadar tentang menulis kode, tetapi juga tentang bagaimana menciptakan solusi yang bermanfaat, efisien, dan mampu menjawab permasalahan nyata."*

- 💡 **Passion:** Mempelajari teknologi baru, mengeksplorasi tools modern, dan mengubah ide menjadi solusi digital fungsional.
- 🎯 **Fokus Riset:** Aplikasi Web, Backend Development, Administrasi Server Linux, Computer Networking, dan Integrasi AI.
- 🛠️ **Penerapan Nyata:** Sistem informasi, manajemen inventaris, infrastruktur server, dan platform digital tepat guna.
- ⚡ **Filosofi:** **Build, Learn, Innovate.**
